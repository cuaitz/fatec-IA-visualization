# fatec-IA-visualization

Projeto de visualização em Python.

## Requisitos

- Python **3.14.6**
- `pip`
- `git`

## Como executar

### 1. Clonar o repositório

```bash
git clone https://github.com/cuaitz/fatec-IA-visualization
cd fatec-IA-visualization
```

### 2. Criar e ativar o ambiente virtual

No Windows:

```bash
py -3.14 -m venv .venv
.venv\Scripts\activate
```

### 3. Instalar as dependências

```bash
pip install -r requirements.txt
```

### 4. Executar o projeto

```bash
cd src
python main.py
```

## Alternar para a branch `maze`

A branch `maze` contém a outra visualização do projeto.

### Ir para a branch `maze`

```bash
git checkout maze
```

### Voltar para a branch anterior

Se quiser voltar para a branch anterior:

```bash
git checkout main
```
